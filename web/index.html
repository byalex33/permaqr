What it does

A short link you own, with a printer-friendly QR on top.

  1. 01

    Redirects that stay fast

    GET /menu looks up the destination in KV and answers 302. The scan is recorded after the response leaves.

  2. 02

    Change the destination

    Point a printed code at a menu today and a gift-card page in December. Pause it when the event is over.

  3. 03

    A real QR designer

    Colours, dot and corner styles, error correction, quiet zone, and an optional centre logo. Preview as you edit.

  4. 04

    Print-ready files

    Export SVG, a high-resolution PNG, or a one-page PDF. Put it on a card, a poster, or a window.

  5. 05

    Privacy-friendly counts

    Totals, a chart over time, countries, and devices. Country comes from the Cloudflare request. The IP is dropped.

  6. 06

    Leave whenever you want

    Export every code and redirect as JSON or CSV. Import them into another PermaQR, or anywhere else.
